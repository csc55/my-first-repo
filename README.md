# my-first-repo

我的第一个 GitHub 仓库。

## 里面有什么

- **`bmi.py`** —— 我的第一个 Python 程序。输入身高和体重,算出 BMI,并判断偏瘦 / 正常 / 偏重。

## 用的什么标准

BMI 判定用的是中国卫生行业标准 **WS/T 428-2013《成人体重判定》**:

| BMI | 判定 |
|---|---|
| < 18.5 | 体重过轻 |
| 18.5 ≤ BMI < 24.0 | 正常 |
| 24.0 ≤ BMI < 28.0 | 超重 |
| ≥ 28.0 | 肥胖 |

**区间是「左闭右开」的** —— 18.5 算正常,24.0 算超重。写代码的时候这一点最容易错。

## 怎么跑

```
python bmi.py
```

## 写这个程序时踩的两个坑

**一、除法的位置**

我一开始写的是:

```python
bmi = weight / height ** 2 / 10000
```

跑出来是 `2.076124567474048e-07` —— 差了一亿倍。那个 `10000` 应该**乘**,不是除。

**二、运算顺序和小数精度**

改对之后还有更细的问题。同样算 96kg / 200cm:

```python
96 / 200 ** 2 * 10000    # 先除后乘 → 23.999999999999996
96 * 10000 / 200 ** 2    # 先乘后除 → 24.0
```

第一个结果比 24 小了一点点,于是被判成「不超重」。

原因是计算机用二进制存小数,`96 / 40000` 存不下精确值。

所以最后定下一条规矩:

> **能最后除,就最后除。**
